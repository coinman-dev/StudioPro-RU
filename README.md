# Fender Studio Pro 8 - Russian Language Pack (Localization)

Полная локализация (русификатор) для Fender Studio Pro 8. Репозиторий содержит обновленные и исправленные файлы перевода, адаптированные для актуальной версии DAW.

## Состав репозитория

1.  **`Russian.langpack`** — Готовый файл языкового пакета. Содержит все последние исправления (включая исправление переменных `$numUpdates`, `$actionTitle` и профессиональную терминологию).
2.  **`Russian-v8.1.yaml`** — Человекочитаемая база всех строк перевода, сгруппированная по контекстам. Удобна для поиска, анализа или внесения правок без использования специальных инструментов.

## Установка

1.  Скачайте файл **`Russian.langpack`**.
2.  Скопируйте его в папку установки программы (по умолчанию):  
    `C:\Program Files\Fender\Studio Pro 8\languages\`
3.  Запустите **Fender Studio Pro 8**.
4.  В верхнем меню выберите: **Studio Pro** -> **Language** -> **Русский**.
5.  Перезапустите программу для применения изменений.

## Основные исправления в этой версии

*   **Брендинг:** Studio One заменен на Fender Studio Pro во всем интерфейсе.
*   **Технические переменные:** Исправлены ошибки отображения системных переменных (например, количество обновлений в диспетчере пакетов).
*   **Профессиональная терминология:** Исправлены неточности машинного перевода (используются термины: *Стемы*, *Квантование*, *Сэмплы*, *Медные духовые* и т.д.).
*   **Полнота:** Добавлены переводы для всех новых модулей и контекстов, отсутствовавших в устаревшем официальном пакете.
