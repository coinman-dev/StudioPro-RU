# Studio Pro 8 - Russian Language Pack (Localization)

Полная локализация (русификатор) для Studio Pro 8. Репозиторий содержит обновленные и исправленные файлы перевода, адаптированные для актуальной версии DAW.

## Состав репозитория

1.  **`Russian.langpack`** — Готовый файл языкового пакета. Содержит все последние исправления (включая исправление переменных `$numUpdates`, `$actionTitle` и профессиональную терминологию).
2.  **`Russian.yaml`** — Человекочитаемая база всех строк перевода, сгруппированная по контекстам. Удобна для поиска, анализа или внесения правок без использования специальных инструментов.

## Установка

1.  Скачайте файл `Russian.langpack`.
2.  Откройте **Studio Pro 8**.
3.  Просто перетащите (Drag-and-Drop) скачанный файл `Russian.langpack` в окно программы или на стартовую страницу.
4.  Программа предложит установить языковой пакет. Нажмите **OK/Install**.
5.  Перезапустите Studio Pro 8.
6.  Перейдите в настройки: `Studio Pro` -> `Options` -> `General` -> `Language` и выберите **Русский**.
7.  Еще раз перезапустите программу.

## Основные исправления в этой версии

*   **Брендинг:** Studio One заменен на Studio Pro во всем интерфейсе.
*   **Технические переменные:** Исправлены ошибки отображения системных переменных (например, количество обновлений в диспетчере пакетов).
*   **Профессиональная терминология:** Исправлены неточности машинного перевода (используются термины: *Стемы*, *Квантование*, *Сэмплы*, *Медные духовые* и т.д.).
*   **Полнота:** Добавлены переводы для всех новых модулей и контекстов, отсутствовавших в устаревшем официальном пакете.
